# P0-4 スパイク結果：YouTube収益のJPY直取得（2026-07-18）

## 検証したこと
YouTube Analytics API に `currency=JPY` を指定して収益を取得できるか、過去期間でも取得できるかを実データで確認した（JP/ENチャンネル両方、読み取りのみ）。

## 結論：JPY直取得は可能。過去期間も取れる
- `metrics=estimatedRevenue` に `currency=JPY` を付けるだけで、Google自身が日次換算した円建て収益が返る
- 過去期間（2026年5月・1月）でも問題なく取得できた → 過去分の再取得・補正が可能
- JP・ENチャンネルとも取得成功

暗黙の換算レート（JPY値÷USD値）は日ごとに 156〜162円で変動しており、実勢に追随している。
現行DB（USD × 固定150円 or 4/20時点のFrankfurterレート）より実態に近い。

## 重要な発見
差は「4/21以降の固定レート」だけの問題ではない。**全月で現行DBがYouTube売上を4〜15%過小計上**している。
これは USD建て×外部レート という換算方式そのものが、Googleの円建て換算より一貫して低く出るため。
（1月・5月・6月で特に差が大きいのは、その時期のドル建て収益構成や為替変動の影響と推測）

YouTube売上は全社売上の約14%なので、全体への影響は月あたり概ね +0.5〜1.5% 程度。

## 推奨（要・加藤さん承認）
1. YouTube取込を **estimatedRevenue の JPY直取得** に切替（外部レート依存・daily_rates・fetch-usd-jpy-rates.ts を廃止）
2. 過去分（2026年以降。取得可能なら全期間）を JPY建てで再取得してDBを上書き → 過去の売上表示が上記のとおり上振れする
3. 影響が大きい月（1月+12.7%、6月+11.4%等）があるため、**上書き適用は加藤さん承認後**に実施

## 実装メモ（承認後）
- youtube.ts の analytics.reports.query に `currency: 'JPY'` を追加
- 保存列を estimated_revenue_jpy 系に変更 or 既存 usd 列の意味を JPY に変更（要スキーマ設計）
- sales_unified_daily の USD→JPY 換算ロジックを撤去（JPYをそのまま使う）
- 過去バックフィルスクリプト＋MV REFRESH
